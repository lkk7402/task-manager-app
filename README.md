# Personal Task Manager

A clean full-stack web application for managing daily tasks with user authentication and CRUD operations.

![Dashboard](screenshots/dashboard.png)

## ✨ Features
- User registration and secure login
- Create, view and delete tasks
- Set task priority (Low/Medium/High) and deadline
- Responsive design
- Session-based authentication

## 🛠 Tech Stack
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (MongoDB Atlas)
- **Frontend**: EJS, CSS
- **Authentication**: Express Session
- **Other**: bcryptjs, Method-Override, dotenv

## 🚀 How to Run Locally

```bash
git clone https://github.com/lkk7402/task-manager-app.git
cd task-manager-app
npm install
cp .env.example .env
npm run dev
